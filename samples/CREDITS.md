# Sample excerpts

The A/B tuner bundles 10-second excerpts of these Creative Commons tracks.
Each file is a trimmed excerpt (the section the tuner plays), re-encoded to
48 kHz Opus at 160 kb/s with metadata stripped. No other changes were made.
